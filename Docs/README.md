# Walls design documentation

Start with [the mockup gallery](Design/index.html) or [the design handoff](Design/README.md).

These deliverables are **high-fidelity UI mockups**: static visual concepts for an iOS app. “Wireframes” usually describe simpler structural drawings; “prototypes” usually describe interactive flows. These are not screenshots of a running app.

PNG files live in `Design/Mockups`. The numbered filenames reflect the reading order. App implementation is outside this design pass.
